Kamus Alat Diagnostik

Penjelasan fungsi perintah dan parameter atributnya untuk pengelolaan jaringan kantor.

1. PING (Packet Internet Groper) Konektivitas

Menguji apakah suatu perangkat (seperti Access Point, Switch, atau Server) sedang *online*/terhubung dan mengukur waktu responsnya (*latency* dalam milidetik).

-t (Win) : Ping terus-menerus tanpa henti (Di Linux/iOS otomatis terus-menerus tanpa atribut).
-n 4 (Win) / -c 4 (Linux/iOS) : Membatasi jumlah paket uji sebanyak 4 kali.
-l 32 (Win) / -s 32 (Linux/iOS) : Mengatur ukuran beban paket data sebesar 32 byte.
2. ARP (Address Resolution Protocol) Pemetaan Fisik

Menerjemahkan dan menampilkan daftar kecocokan antara alamat IP dengan alamat fisik perangkat (**MAC Address**) yang tersimpan di memori lokal.

-a : Menampilkan seluruh tabel pemetaan IP ke MAC Address yang aktif. Sangat berguna untuk melacak perangkat asing atau mencari tahu MAC Address Access Point.
3. TRACERT (Win) / TRACEROUTE (Linux/iOS) Jalur Rute

Melacak titik-titik lompatan (*hop* / router / switch Layer 3) mana saja yang dilewati oleh paket data untuk mencapai tujuan. Berguna mencari titik kemacetan jaringan (*bottleneck*).

-d (Win) / -n (Linux/iOS) : Mempercepat pelacakan dengan tidak menerjemahkan IP ke nama domain.
-h 30 (Win) / -m 30 (Linux/iOS) : Membatasi jumlah lompatan maksimal 30 router.
4. NMAP (Network Mapper) Audit & Keamanan

Memindai perangkat secara mendalam untuk melihat *port* layanan apa saja yang sedang terbuka (misal: port 80 untuk web, 22 untuk SSH) serta mengaudit keamanan server.

-sV : Mendeteksi versi aplikasi/layanan secara spesifik yang berjalan di balik port yang terbuka (misal: *Nginx 1.24*).
-O : Mendeteksi jenis Sistem Operasi (OS) dan vendor perangkat keras pada jaringan.
-p 1-1000 : Memfokuskan pemindaian hanya pada rentang nomor port 1 hingga 1000.
5. NSLOOKUP (Name Server Lookup) Diagnosa DNS

Menguji server DNS lokal untuk memastikan nama domain internal (seperti halaman login `cas.kantor.lokal`) mengarah ke alamat IP server yang tepat.

-type=A : Mencari alamat IPv4 dari sebuah nama domain (*Address record*).
-type=PTR : Kebalikannya (*Reverse DNS*), mencari tahu apa nama domain dari sebuah alamat IP.
6. IPCONFIG (Win) / IFCONFIG & IP (Linux/iOS) Info Lokal

Menampilkan konfigurasi alamat IP, Subnet Mask, dan Default Gateway dari perangkat yang sedang Anda gunakan, serta mengelola memori DNS lokal.

ipconfig /all (Win) / ip addr show (Linux) / ifconfig -a (macOS/iOS) : Menampilkan informasi lengkap kartu jaringan & MAC Address.
ipconfig /flushdns (Win) / resolvectl flush-caches (Linux) : Menghapus dan menyegarkan kembali memori (*cache*) DNS.
7. NETSTAT (Network Statistics) Sesi Koneksi

Memantau lalu lintas koneksi yang sedang aktif keluar-masuk dari perangkat Anda secara langsung (*real-time*).

-a : Menampilkan seluruh koneksi aktif dan port yang sedang mendengarkan (*listening*).
-n : Menampilkan alamat dan port dalam bentuk angka numerik murni (`192.168.56.1:80`) agar tampil lebih cepat.
-o : Menampilkan nomor *Process ID* (PID) untuk melacak aplikasi apa yang diam-diam menggunakan jaringan.
8. cURL (Client URL) Uji Web Server

Menguji respons layanan web (HTTP/HTTPS) langsung dari baris perintah. Sangat pas untuk mengecek apakah server autentikasi CAS atau halaman login Captive Portal sedang berjalan normal (`200 OK`).

-I : Hanya mengambil informasi *Header HTTP* (status server, tipe web server) tanpa mengunduh seluruh isi kode HTML halaman.
-k : Mengizinkan pengujian koneksi ke server HTTPS internal meskipun menggunakan sertifikat SSL lokal (*self-signed certificate*).
